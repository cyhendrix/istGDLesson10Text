# Lesson 10: Text

Original practice activities based on Code.org CSD Unit 03, Lesson 10. Curriculum: CC BY-NC-SA 4.0. Purple/gold classroom practice; no roster or credentials are stored here.

## Activities
Identify: 6 matching items; Build: 3 code-order tasks; Apply: 4 questions; Debug: 4 questions. Total: 17 points. Orders and choices shuffle once per attempt. Each tab permits at most two checks; a perfect first check completes it. Progress saves in this browser. Reset Entire Lab on every tab clears only the local attempt after confirmation.

## Publishing
GitHub Settings → Pages → Deploy from a branch → main → / (root).
